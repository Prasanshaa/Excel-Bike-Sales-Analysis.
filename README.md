# 🚲 Bike Sales Analysis | Excel

## 📌 Project Overview

An Excel-based data analytics project focused on analyzing customer demographics and bike purchasing behavior.

The project uses data cleaning, Excel formulas, Pivot Tables, Pivot Charts, and an interactive dashboard to identify patterns in customer purchases based on income, age, gender, commute distance, and other demographic factors.

---

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- IF Function
- Pivot Tables
- Pivot Charts
- Data Visualization
- Dashboard Development

---

## 📊 Dataset

The dataset contains customer-level information including:

- Customer ID
- Marital Status
- Gender
- Income
- Children
- Education
- Occupation
- Home Ownership
- Number of Cars
- Commute Distance
- Region
- Age
- Bike Purchase Status

---

## 🔄 Project Workflow

### 1. Data Cleaning & Preparation

- Reviewed and organized the raw customer dataset.
- Standardized categorical values for analysis.
- Created additional fields required for analysis.

### 2. Data Transformation

Created an **Age Bracket** column using Excel formulas to categorize customers into different age groups.

### 3. Pivot Table Analysis

Created Pivot Tables to analyze:

- Average income by gender and bike purchase status.
- Bike purchases by commute distance.
- Bike purchases across different age brackets.

### 4. Dashboard Development

Created an interactive Excel dashboard to present key customer and bike purchasing insights through charts and visual summaries.
